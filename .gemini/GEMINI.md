# Project Context: ScholORs Lab Website

## Core Objective
Build a single-page laboratory website hosted on GitHub Pages.

## Tech Stack Constraints
- **Language:** Raw HTML, CSS, JavaScript.
- **Frameworks:** NONE (No React, Vue, Bootstrap, etc.). Start from scratch for maintainability and learning.
- **Hosting:** GitHub Pages.

## Key Content Sections
1.  **Team Introduction:**
    - Research directions.
    - Member bios/photos.
2.  **Embeds/Integrations:**
    - **Publications:** Display papers (Plan: List + ResearchGate link).
    - **Projects:** Display GitHub repositories (Plan: GitHub API or manual cards).
    - **News:** LinkedIn updates (Plan: Recent highlights + Link).
3.  **Contact:**
    - Microsoft Forms embedding.

## Design
- Single page with sticky navigation.
- Simple, clean, maintainable.
